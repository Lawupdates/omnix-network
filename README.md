# OMNIX — Universal Crypto Network

**Status: early-stage frontend prototype. Not a live exchange or cryptocurrency.**

This repository hosts the OMNIX concept website. The conversion calculator uses fixed illustrative prices, not live quotes. It does not trade, bridge, custody or transfer funds. No OMX token exists through this site.

## Site

After GitHub Pages is activated, the intended URL is https://lawupdates.github.io/omnix-network/ . Website source: `index.html`.

## Deployment

This repository contains `.github/workflows/pages.yml` for GitHub Pages Actions deployment. In GitHub repository **Settings → Pages**, set **Build and deployment → Source → GitHub Actions**. If automatic deployment is not available, choose **Deploy from a branch → main → /(root)**.

## Before any actual mainnet launch

- Retain qualified digital-asset legal counsel to evaluate jurisdictions and regulatory compliance.
- Vet and integrate supported wallets, liquidity providers, chains, bridge contracts and price oracles.
- Review allowances, slippage protections, refund/recovery paths and transaction monitoring.
- Complete independent audits, security testing, incident response planning and privacy/terms documentation.
- Design and legally review any actual OMX token only if utility is justified.

**Never provide seed phrases or send funds to purported OMNIX token sellers.**
