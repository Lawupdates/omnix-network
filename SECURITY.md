# OMNIX security policy

This site is an informational prototype and should never request private keys, mnemonic seed phrases, or deposits. It has no production smart contracts and no audited payment or custody system. No security audit or certification is claimed.

Do not treat sample conversion figures as market quotes. The source code is publicly inspectable in this repository. Before launch, complete independent security reviews of any future contract, API, custody design, wallet interaction and third-party integration.

To report an issue, open a GitHub issue without including credentials, personal keys, or exploit data that puts users at risk.
